# Codegen

## Locals
- Each layer is one local in `fragment()`, in stack order, named `l<id>`. (`DESIGN.md` Codegen rules, `GSTUniformNames.local_var`)
- A generator's coord local is `coord<id>`. (`GSTUniformNames.coord_var`)
- Coord order: `transform(space_coord, scale, rotation, offset)`, then `+= scroll * TIME`, then `+= vec2(l<wx>, l<wy>) * warp_strength`. A missing warp axis contributes `0.0`. (`DESIGN.md` Codegen rules)
- Space input: `uv` reads `UV`, `screen_uv` reads `SCREEN_UV`, `local` reads `local_pos`. (`DESIGN.md` Codegen rules)

## `TIME` and scroll
- Scroll uniform and `TIME` term are emitted together or not at all. (`DESIGN.md` Codegen rules, review revisions)
- Zero scroll at export emits neither, so a static stack has no `TIME`. (`DESIGN.md` Codegen rules)

## Uniforms
- One uniform per slider param, with `hint_range(min, max)` and the layer's value as default. (`DESIGN.md d7`, Codegen rules)
- Param uniform: `l<id>_<function>_<param>`. (`DESIGN.md d7`, `GSTUniformNames.param_uniform`)
- Coord uniforms carry no function segment: `l<id>_scale`, `l<id>_offset`, `l<id>_rotation`, `l<id>_scroll`, `l<id>_warp_strength`. (`PLAN.md B4`)
- Group line per layer: `group_uniforms L<pos>_<function>;`, `pos` two-digit zero-padded, `0` is bottom. A bare numeric group name does not compile. (`PLAN.md B3`, `GSTUniformNames.group_line`)
- `addons/goshade_turbo/codegen/gst_uniform_names.gd` is the single source of every uniform and group name. (`PLAN.md cross-cutting`)
- Uniform naming is frozen: no migration path exists for shaders already exported. (`PLAN.md cross-cutting`)

## Functions
- Include walk: depth first over `depends`, dedupe by id, every body before `fragment()`. (`DESIGN.md` Codegen rules)
- `function` is unique across the roster. (`DESIGN.md` Manifest entry, `GSTManifestEntry.function`)
- `luma` is emitted once, only when a conversion needs it. (`PLAN.md` phase 3 verification)

## Sources and filters
- Source entries have empty `code`; codegen emits the read expression. (`PLAN.md cross-cutting`, manifest `code` contracts)
- Screen sampling uses `uniform sampler2D gst_screen_texture : hint_screen_texture`. (`gst_codegen.gd:65`, `PLAN.md B10`)
- A filter's `code` is an inline body template, expanded into a `{ }` block inside `fragment()` per filter layer. Filters are never GLSL functions. (`PLAN.md B10`)
- Template tokens: `GST_SAMPLE(p)`, `GST_UV`, `GST_OUT`, `GST_PARAM(name)`. (`PLAN.md B10`, `GSTManifestEntry.samples_source`)
- `GST_UV` maps to the wired source's raw `UV` or `SCREEN_UV`, never the stack's coord space. (`gst_manifest_entry.gd:47-48`)
- No `gst_self_texture` uniform exists. (`PLAN.md B10`)
- An unknown `GST_` token left after expansion is a codegen error. (`GSTCodegen.generate_result` doc comment)

## Output line
- `COLOR = vec4(l<c>.rgb, <alpha>)`; alpha is `1.0`, `texture(TEXTURE, UV).a`, `l<c>.a` or `l<a>`. (`DESIGN.md` Codegen rules)
- Layer preview replaces the output with the selected layer, fields as `vec4(vec3(lN), 1.0)`. It never changes exported text. (`DESIGN.md` Codegen rules, `EDITOR_UI d14`)

## Header and export
- Header order: a `// Generated by GoShade Turbo.` line, one copyright line per included function ported from a third-party source, the MIT notice once, then `// stack: <json>` on one line. (`docs/USAGE.md` Export, `d466191`)
- The export claims no license for the user's stack. (`docs/USAGE.md` Export, `d466191`)
- Header json carries a schema version (`GSTHeader.SCHEMA_VERSION`). (`PLAN.md cross-cutting`)
- Reopen refuses a missing header, an unparsable header or an unknown schema with a message naming the file and reason. No partial parse, no empty stack offered. (`PLAN.md B8`, `PLAN.md cross-cutting`)
- Reopen from header warns when the body differs from a fresh codegen. (`DESIGN.md d8`)
- Export compares the target body to a fresh codegen of its own header and asks before overwriting a differing body. (`DESIGN.md d9`)

## Errors
- `GSTCodegen.generate_result` returns a `GSTCodegenResult` (`code`, `error`, `ok()`); `generate` returns `""` on error. (`PLAN.md cross-cutting`)
- Codegen state is invocation-local, never class-global mutable state. (`PLAN.md cross-cutting`)

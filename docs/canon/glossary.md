# Glossary

- `stack`: one `GSTStack` resource; an ordered list of layers, index `0` at the bottom. (`DESIGN.md` Data model)
- `layer`: one `GSTLayer`; one library function with its params, inputs and optional coord block. (`DESIGN.md` Data model)
- `layer id`: stable `StringName` from `next_id`, never reused. (`DESIGN.md d22`)
- `kind`: a layer's output type, `field` or `color`. (`DESIGN.md d2`)
- `field`: one float per pixel, usually `0` to `1`. (`DESIGN.md d2`, `README.md` Usage)
- `color`: one RGBA vec4 per pixel. (`DESIGN.md d2`)
- `generator`: a layer with a coord block and no inputs. (`DESIGN.md d14`)
- `operator`: a layer with typed inputs and no coord block. (`DESIGN.md d14`)
- `source`: `source/texture` or `source/screen`; reads a texture. (`DESIGN.md d10`)
- `filter`: a layer with `samples_source: true`; samples a source at neighbor offsets. (`DESIGN.md d21`)
- `coord block`: a generator's scale, offset, rotation, scroll and warp. (`DESIGN.md d4`)
- `coord space`: the stack's input coordinate, `uv`, `screen_uv` or `local`. (`DESIGN.md d11`)
- `slot` / `input`: a named operator input holding a lower layer's id. (`DESIGN.md` Data model, `EDITOR_UI d3`)
- `warp`: the coord block's `warp_x` and `warp_y` inputs. UI: distortion. (`DESIGN.md d4`, `EDITOR_UI d30`)
- `conversion`: the automatic grayscale or luminance wrap at a kind boundary. (`DESIGN.md d2`)
- `fallback constant`: the typed value codegen uses for an unset input. (`gst_codegen.gd:10-14`)
- `output block`: `output_color` plus `output_alpha`. UI: Final output. (`DESIGN.md d12`, `EDITOR_UI d13`)
- `solo`: the layer preview mode. UI: Preview this layer. (`DESIGN.md d13`, `EDITOR_UI d14`)
- `manifest entry`: one `GSTManifestEntry` `.tres` describing one library function. (`DESIGN.md d5`)
- `library`: every manifest under `addons/goshade_turbo/library/`. (`docs/LIBRARY.md`)
- `roster`: the set of entries the library ships. (`DESIGN.md` roster)
- `include walk`: depth-first collection of `depends` bodies for export. (`DESIGN.md` Codegen rules)
- `body template`: a filter's inline `code` with `GST_` tokens. (`PLAN.md B10`)
- `recipe`: a bundled starting stack under `addons/goshade_turbo/recipes/`. (`DESIGN.md` Recipes)
- `reference stack`: a stack under `sandbox/stacks/` showing one entry at default sliders. (`DESIGN.md` release checklist)
- `header`: the comment lines of an exported shader, ending with `// stack: <json>`. (`DESIGN.md d8`, `docs/USAGE.md` Export)
- `schema`: the header json version, `GSTHeader.SCHEMA_VERSION`. (`PLAN.md cross-cutting`)
- `overwrite check`: export's comparison of a target body against a fresh codegen of its own header. (`DESIGN.md d9`)
- `document`: one open shader tab with its stack, path, history and preview state. (`SHADER_TABS d3`)
- `refusal`: a rejected edit, reported beside its control with no undo action. (`EDITOR_UI d6`)
- `randomize`: slider randomization inside manifest ranges on an open recipe. (`DESIGN.md d16`)
- `rendered checks`: GPU pixel checks for NaN, inf, alpha range and uniform output. (`DESIGN.md` release checklist)
- `combination test`: every operator compiled with every compatible input entry. (`DESIGN.md` release checklist)
- `editor smoke`: scripted checks run inside a real editor via `GST_EDITOR_SMOKE`. (`PLAN.md` phase 4)
- `smoke seam`: a public accessor that exists only for the editor smoke. (`PLAN.md cross-cutting`)
